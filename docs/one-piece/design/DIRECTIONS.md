# Three direction proposals before rendering

Status: **proposals, not selected or visually accepted**. Same catalogue truth, fixture content and target viewports as the brief. No interface implemented yet. All use code-native abstract lines/number forms; none depends on anime artwork.

## A — Blue-hour cinema

**Idea:** A calm screening room where the next episode is the largest object and the library is an orderly shelf beneath it.

- Desktop composition: a wide horizontal Continue region uses Episode **1000** as the typographic anchor. Resume and Cast sit beside its progress line; 1,084-episode catalogue/range controls occupy one compact band below. Episode rows form two balanced columns rather than poster cards. Narrow left edge carries only Library/Watch navigation and a small drawn horizon/compass mark.
- Phone translation: remove the side rail; Continue becomes the first compact vertical block, not a full-screen billboard. Search follows immediately, then one-column rows. Navigation lives at the top; the primary action remains reachable without a second screen.
- Type/density: large plain humanist episode numerals, restrained small uppercase navigation, generous spacing around the current episode and denser rows beneath. Deep ink/soft white with one muted sea-glass action colour; no glows, gradients or glass cards.
- Interaction meaning: the current selection grows into the Watch picture area. Preparing uses the same Continue region with stage and Cancel, preserving identity instead of opening an unrelated dashboard. Remote mode replaces the picture with a large episode/time controller.
- Watch: wide dark stage at desktop; controls in a single quiet band, current/next below. Portrait phone keeps 16:9 picture plus thumb-friendly transport/destination controls.
- Main risk to test: an oversized continue region can push actual browsing off the phone. A critic should reject any cinema treatment that depends on imagery or creates a vacant hero.

## B — The ship log

**Idea:** An enduring reading log for a long voyage: one clear place to continue, followed by numbered entries that remain easy to scan years into the series.

- Desktop composition: warm off-white page, narrow masthead, large serif `One Piece` wordmark paired with monospaced episode numbers. A broad left section shows Continue and the episode ledger; a slim right column holds numeric ranges, account and local-home status. Thin horizontal rules carry grouping instead of nested cards.
- Phone translation: the range index becomes a compact horizontal jump control directly above the ledger. Continue reads as a prominent two-line entry with one solid Resume button; every episode is a comfortable full-width ruled row. Header and body remain typographically distinct without large art.
- Type/density: editorial title/section typography, tabular number column and readable sans-serif metadata. Mid-density list; unusually clear alignment makes a long catalogue feel composed. Warm paper/ink/oxidized teal, no faux parchment texture, torn edges or decorative rope.
- Interaction meaning: selection marks the current line with a solid margin tick. Progress is a short line integrated into the continue entry. Missing 590 is an explicit interrupted entry; continuing to 591 is a deliberate action. A reversible details disclosure explains preparation and source issues.
- Watch: dark picture stage deliberately switches the reading surface into a screening surface; a paper strip below retains episode identity, next action and language controls. Remote controller uses the same ledger hierarchy rather than mimicking a black video rectangle.
- Main risk to test: mixed serif/mono/sans can become over-designed or reduce phone readability. Avoid simulated log-book copy and arbitrary nautical labels for standard controls.

## C — Episode guide

**Idea:** A practical programme guide: a permanent ordered episode index and a focused selected-episode pane make navigation through 1,084 episodes immediate.

- Desktop composition: split view with a 360 px episode/range index on the left and a large selected-episode workspace on the right. Header carries account and current TV destination. Continue is a pinned selected row and a matching primary action in the detail pane; no separate hero or repeated content carousel.
- Phone translation: master/detail navigation with an explicit `Back to episodes`; Library is the full-width list and Watch is the full-width selected surface. Returning restores exact list position. Search and range selection occupy a compact sticky index header, with clear content inset below it.
- Type/density: system sans-serif and tabular medium-weight episode numerals; tighter desktop spacing, more generous phone rows. Soft cool neutral surfaces, thin selected-row side bar, one strong coral play action. No shadows on every row.
- Interaction meaning: changing the selected row previews status and actions without immediately starting playback. Previous/Next traverse the same ordered index. Cast remote retains the index and opens a destination-specific selected pane; preparation state is shown on the selected row and detail pane without hiding other episodes.
- Watch: on wide desktops the compact index remains available beside the video; a theatre/fullscreen mode removes it. The phone uses the whole width, then a short next-entry strip.
- Main risk to test: split-pane density can feel like an administrative tool and duplicate the selected episode. The visual critic must evaluate emotional calm and watch focus, not merely reward the number of visible rows.

## Comparison intent

| Axis | A | B | C |
|---|---|---|---|
| Primary composition | Large current-episode region over library | Ruled reading surface with supporting range index | Master/detail episode index |
| Typographic personality | Large modern numerals / humanist sans | Editorial serif + aligned mono numerals | Compact system sans / tabular numerals |
| Desktop density | Spacious current, moderate list | Balanced ledger | Dense index, focused detail |
| Phone relationship | Compact cinema block then list | Continuous numbered reading surface | List-to-detail with preserved position |
| Key interaction | Current object becomes Watch | Current entry stays anchored through states | Selected row controls a dedicated workspace |

The independent critic should compare matched actual renders and all declared dimensions. No direction is recommended before that comparison; functional plausibility is not visual acceptance. The chosen direction may borrow a useful mechanism from another only with a concrete retain/change rationale.
