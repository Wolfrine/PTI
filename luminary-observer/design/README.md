# Luminary Design Memory

Status: Active  
Updated: 2026-09-23

This folder is the local design-governance source for Luminary.

## Current state

- Product architecture and capture behavior remain active.
- The **Living Instrument v1 visual direction is rejected as a final art direction**.
- Do not spend cycles merely polishing the existing dark/cyan/violet/orbital aesthetic.
- Do not remove working product behavior simply because the visual language is being reset.

## Required inputs before redesign

1. Central design protocol and design intelligence.
2. Luminary product constraints from `../EXPERIENCE_SYSTEM.md` (product/behavior portions only).
3. A compact real-reference pack.
4. At least two materially different art-direction candidates.
5. Prototype/render evidence for Entry + Observe + one derived-pattern state.
6. Independent visual critique on mobile and desktop.

## Local files

- `DESIGN_DIRECTION.md` — constraints and direction for the next exploration.
- `SCREEN_QUALITY_MAP.md` — current screen-level status.
- `UI_REVIEW_NOTES.md` — why v1 was rejected and what to test next.
- `UI_DECISIONS_LOG.md` — durable owner/design decisions.
