# Luminary V4 — Layered Design Audit

Status: Active
Date: 2026-09-24

This audit intentionally does **not** treat V2 or V3 as all-good/all-bad directions.

## Owner signal

Owner assessment:
- V2 was more premium and decent than V3.
- V2 font, layout, sizing and color worked.
- V2 failed mainly in design meaning, visuals and meaningful motion.
- V3 improved clarity but lost premium quality and still did not establish meaningful visuals/motion.

## Retain / refine / replace

| Design layer | V2 | V3 | V4 action |
|---|---|---|---|
| Typography | Strong | More ordinary | **Retain V2** |
| Color | Strong, restrained | Similar but flatter | **Retain V2** |
| Sizing/proportion | Strong | Conventional | **Retain V2** |

## V4 thesis

> **A moment should visibly become a preserved object.**

The product-specific idea is not a timeline, node graph, orbit or abstract field.

The key visual object is a **Moment Imprint**:

1. it is born when Mark / Speak / Write is preserved;
2. it visibly settles into the raw Stream;
3. the same object reappears later as evidence beneath a Pattern;
4. it always represents one real source observation.

The object is therefore learned through use rather than explained through a legend.

## Motion hierarchy

### Capture
present -> press -> imprint forms -> confirmation -> imprint leaves the capture surface

Meaning:
A fleeting moment has become part of the record.

### Stream
imprint -> raw observation expands

Meaning:
The small preserved object is the same source record, not a separate visualization.

### Patterns
plain-language pattern statement -> supporting imprints gather/reveal -> source detail

Meaning:
The derived pattern is supported by specific recorded moments.

### Navigation
minimal continuity only.

Meaning:
Do not animate navigation for spectacle.

## Emotional target

| State | Intended feeling |
|---|---|
| Entry | quiet curiosity |
| Observe idle | calm readiness |
| Mark press | decisive capture |
| Save confirmation | subtle satisfaction / permanence |
| Stream | trust in accumulated record |
| Patterns | recognition / discovery, not diagnosis |

## Non-goals

- no particles;
- no neural/node diagrams;
- no decorative temporal coordinates;
- no magical causal connections;
- no gamified success burst;
- no repeated animated flourish on frequent actions;
- no loss of V2's premium foundations merely to appear “new”.

## Acceptance gate

V4 must answer these without explanatory copy:
1. What can I do here?
2. What happened when I pressed Mark?
3. Where did that moment go?
4. Why are these moments shown under this pattern?
5. Is the pattern an explanation or only a recurrence?

Do not merge/deploy until owner sees motion evidence.
