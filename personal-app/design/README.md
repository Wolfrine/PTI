# Personal / design contract

L2 editorial intelligence journal. Read the relevant Central/design protocol, execution routing and perceptual foundations; do not copy their corpus. Scope is Personal only.

Thesis: source visual → claim/evidence → your response → dated reflection. A finite edition, not an administrative dashboard or an endless engagement feed. Paper/ink/rust, serif article hierarchy, one lead story and smaller subsequent entries. Proximity keeps feedback with its article; containment separates evidence from interpretation. Native disclosures progressively reveal detail; short press/selection transitions communicate state. Reduced motion preserves all information.

## Story imagery: owner correction, 29 September 2026
Use a relevant original source image, or an actual story-specific illustration made with the current native ChatGPT Image Gen tool. Generated art must be inspected, hosted and honestly labelled. Do not substitute SVG, canvas, CSS, Python/Pillow drawings, stock placeholders or native concept sketches. Ordinary interface icons are outside this restriction. Resize/compress actual generated rasters, never redraw them. Do not invent a precise model-version claim when the tool does not expose it.

The previous concept-sketch fallback is rejected and removed from the renderer. Missing, disabled or failed images get a text-only availability state, not substitute art. Reject unrelated dashboard outputs and do not crop them into fake article illustrations. Source imagery remains credited, including source-produced diagrams/CAD views. Never mislabel an illustration as an event photograph. No decorative orbit/glow/network metaphor. No unsourced outlet trust score.

Today, Capture, Threads and Reflection are distinct tasks. Saving a source is not an inferred endorsement. Missing reaction means unknown. Reflections cite explicit source records, show partial-day status, and are hidden after a supporting response changes or is deleted. Private captures are excluded from agent interpretation.

Rendered-browser fallback: prior actual modules bundled with synthetic demo state were inspected at 1440, 768, 390 and 360px. The mobile masthead was reduced and flows rerun. CI serves built modules and retains fresh screenshots for each change; workflow results, not this document, establish current deployment verification. Image-policy regression tests cover missing assets, legacy concept records, actual asset labels, signed URLs, unsafe URLs and disabled loading. No user records enter fixtures.

Acceptance: an approved visual per new story; readable image credit and claim classification; source/limitations disclosure; 44px primary tap controls; labelled forms/focus; mobile navigation; no overflow; finite ending; reflection traceability; explicit empty/error/sample states; no private response caching. If image generation fails, report the gap rather than claiming completion. The owner remains final taste authority.
