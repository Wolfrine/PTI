# Shared studio direction pack

Studio goal: the owners' discussion produces traceable directions, evidence, decisions and experiments. L3 product craft with L2 working efficiency. Actual artifacts are the visual material; generated illustration would add no useful evidence.

| Reference | Mechanism used | Avoid copying |
|---|---|---|
| Seasats | Same fields make directions directly comparable; navigation maps real working modes. | Maritime imagery and decorative sectional stripes. |
| Linear | Group by human workflow; low chrome reserves focus for real work. | Black/lavender SaaS skin. |
| Collection | Direction titles express the actual intervention before metadata. | Quirky copy, generic serif pairing. |
| Material | Containment groups source words; expansion preserves selected object; visible response follows actions. | Repeated elevation or expressive shapes without meaning. |
| MagicPath | Human/agent output occupies the same work surface with artifact-level provenance and explicit execution status. | Infinite canvas or simulated agent progress. |

Selected thesis: **A discussion fans into tangible direction sheets; evidence and decisions stay attached to the exact direction they change.**

Two materially different prototypes in `exploration.html`: branching worktable (recommended), shared folio (alternative). The folio is chronological and reading-led; the worktable is spatial and choice-led. Existing Evidence Desk/ledger remains rejected for the shared studio journey. Do not revive abstract Market Observatory graphics: actual stored parent/source links alone can connect objects.

Perceptual grammar: proximity and common region bind source to claim; directed continuation represents stored lineage; rust edge indicates selection, moss indicates an acknowledged decision; expanded sheet is the same selected direction. These grouping/continuity mechanisms have stronger evidence than hypothesized affect. Intended tone is approachable working confidence, not a measured emotional response.

Motion: new direction sheet enters from source position; evidence appears inside its owning sheet; selection moves the selected sheet into focus. Reduced motion keeps immediate boundaries and state labels.

Phone: discussion and direction tabs; one focused artifact with accessible bottom mode navigation. Never shrink the desktop map.

Anti-pattern checked: Generic AI UI. No glow, orbs, atmospheric gradients, equal bento cards, decorative graphs or automatic agent activity.
