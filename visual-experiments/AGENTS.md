# Instructions for `visual-experiments/**`

Read [README.md](README.md) and [evals/README.md](evals/README.md). This folder is exempt from PTI's inherited Angular UI conventions and Central design procedure. Repo-wide security and deployment protections still apply.

## Codex

1. Begin an evaluated experiment only when Work's eval criteria and method are ready. Choose the concept, medium, tools and direction **independently**; briefly record what you chose and why.
2. Build a **runnable** experience. Inspect actual browser output and applicable interactions, not only source code or still images.
3. Execute applicable evals. Tie results and minimal reproducible evidence to the source revision. Mark failures, blockers and unrun checks accurately; do not claim Work or owner approval.
4. Correct observed problems and repeat checks as needed. No fixed iteration count or prescribed aesthetic. Record findings in the experiment README.

**Boundaries:** Keep changes within `visual-experiments/` unless specifically authorized. Do not change existing apps, shared Firebase/Auth/Firestore data or rules, Central, or production deployment. This harness configures no live site; deployment needs a separately approved target.
